CADScene Workbench Windows 离线测试包

1. 请先完整解压 ZIP，不要直接在压缩软件中运行。建议解压到 D:\CADScene 等较短目录，
   不要在下载目录中重复嵌套同名文件夹。
2. 双击“启动CAD视频工作台.cmd”。首次启动会整理包内环境，通常需要几十秒。
3. 浏览器会自动打开“项目文件”页面，可新建项目并上传 MP4、DXF 和可选 SRT。
4. 用户项目和运行结果只保存在当前目录的 workspace 文件夹中。
5. 使用结束后双击“关闭CAD视频工作台.cmd”。

同一台电脑从旧版升级：

1. 先关闭旧版和新版工作台。
2. 完整复制旧版的 workspace 文件夹，覆盖新版程序目录中的 workspace；不要只复制 projects。
3. 保留旧版程序目录并启动新版。首次启动会校验副本，把旧 workspace 改名为
   workspace.pre-0.1.3-时间戳，并在旧版原位置建立指向新版数据的兼容 Junction。
4. 项目验收无误后可以删除上述带时间戳的备份，但请勿删除旧版原位置自动建立的 workspace Junction，
   否则旧项目 manifest 中保存的绝对路径将再次失效。
5. 该迁移只支持同一台 Windows 电脑；换电脑时盘符和历史绝对路径不同，不能使用此方式。

如启动失败，请保留整个目录，并将 logs 文件夹中的 doctor.txt、service-stdout.log 和
service-stderr.log 一并反馈。请勿同时启动本包的多个副本访问同一个 workspace。

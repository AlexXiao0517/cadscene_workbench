# 全姿态 SRT：高程与统一渲染接入

- 全姿态轨迹适配器 v5：直接读取 SRT，不执行 SfM；最后一条字幕在自身半开有效时段内仍可提供位姿，不外推到字幕结束之后。缺失姿态适配器 v8 在联合约束前使用同一高度选择规则。
- 对任务冻结全部 TPKG 路径、内容指纹及 CAD 指纹，投影到同一 CAD 局部坐标后合并。输出 terrain_context.json、terrain_controls.npz、camera_calibration.json，并纳入产物校验和缓存身份。
- 高程覆盖率、跨文件冲突和相机垂直基准状态传到工作台。TPKG 提供 CAD 线/文字的地形 Z，不代表已确定相机的起飞点高程。
- 有可用地形且整条有效轨迹有 abs_alt 时：相机 Z 使用 abs_alt 加用户明确设置的偏移，CAD Z 使用 TPKG 原始高程。恢复此前 XML/COLMAP 后端实验策略，不添加自动起飞点补偿，不自动做椭球高转换。标注 srt_abs_alt_unverified，不能声称测量验证过垂直基准。
- 无地形、完全不覆盖轨迹或 abs_alt 不完整时：整条路线使用相对高度路径，CAD Z=0。禁止逐帧混用相对高与绝对高。高程文件与覆盖诊断保留；关键帧微调和路线拟合仍可用。
- 全姿态和缺失姿态渲染适配器 v8：关键帧对齐/拟合 → calibrated_overlay → 项目视频封装。保留 720p / 1080p / 原始 / 4K 分辨率选择；旧视频缓存不作为 v8 结果复用。
- 全姿态相机内参来自用户水平 FOV；无畸变标定来源时 k1/k2 按零使用，并明确标注未知，不冒充三维重建标定。
- 渲染 CLI 使用现有 H.264 编码器解析逻辑，避免系统 PATH 中仅解码版 FFmpeg 导致导出失败。
- 历史结果须重新生成才能获得上述产物；不覆盖用户关键帧存档，不自动替用户确认高度，也不替用户保存工作台。

## 恢复已验证后端渲染规则

- CAD 使用原有加载器的线条集合和原色，按路线包围盒外扩 500 m 筛选，20 m 加密；不绕过加载器直接绘制全部 design.json 实体。
- 地形模式优先使用 TPKG 线的原始 Z，2 m 采样，CAD 两端都在 160 m 控制距离内才绘制。不把未覆盖区域强行贴到中位高程；仅点高程文件保留点控制回退。无高程相对模式不做覆盖裁剪。
- 中文优先从原始 DXF 恢复，回退 design.json；与线路使用相同高程，文字抬高 0.3 m。每帧最近优先、重叠避让、最多 24 条，恢复原黑体字体和尺寸规则。
- 默认线宽 2、透明度 0.92、距离 350 m、260 m 起淡化，恢复 12 档抗锯齿遮罩及批量线条绘制。平台入口和标定渲染 CLI 一致，非标定旧流程默认值不变。
- 校验：当前项目同一相机/视频/CAD/高程输入，预处理得到 37,286 条线段、151 条标注，与保存的 render_backend_at_preview.py 一致。第 0、3000、6000 帧新旧输出逐像素一致。此比较证明渲染实现一致，不证明当前视频的用户 FOV、姿态和垂直基准已经标定准确。

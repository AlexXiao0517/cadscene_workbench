# 自定义中央经线输入设计

## 目标

CAD 地理参考配置同时支持十进制度和度分输入。用户输入 `118°50′` 时，系统必须按精确的 `118.833333333333°` 构造 CGCS2000 高斯—克吕格投影，而不是取整、四舍五入或退回最接近的标准 EPSG 中央经线。

本次只增加“已知 CGCS2000、已知自定义中央经线、其余投影参数采用约定默认值”的路径。七参数、四参数、关联点拟合和任意椭球体不在本次范围内。

## 输入与规范化

中央经线输入改为文本字段，允许以下等价形式：

- `118°50′`
- `118°50'`
- `118 50`
- `118.833333`
- 原有整数形式，例如 `120`

度分形式中，分必须位于 `[0, 60)`；符号作用于整个角度；最终十进制度必须位于 `[-180, 180]`，且 `180°` 只能搭配 `0′`。空值继续表示“根据 SRT 位置自动推荐”。输入解析失败时不发起候选任务，并在字段旁显示可操作的格式错误。

浏览器将输入规范化为十进制度后提交。HTTP API 和服务层仍必须接受数字或上述字符串，统一调用同一个解析函数，避免绕过前端时出现不同语义。候选任务请求和输入指纹只保存规范化后的十进制度，使等价写法复用同一个任务。

## 投影选择

规范化后的中央经线先尝试匹配 PROJ 数据库中的 CGCS2000 高斯—克吕格 EPSG：

- 能精确匹配时沿用现有 EPSG 候选，例如 `120°` 使用 EPSG:4549。
- 不能匹配时生成自定义 CGCS2000 横轴墨卡托候选，例如 `118°50′`。

自定义投影参数固定为：

```text
datum/geographic CRS = CGCS2000 (EPSG:4490, GRS80)
method               = Transverse Mercator / Gauss-Kruger
latitude of origin   = 0°
central meridian     = 用户规范化后的十进制度
scale factor         = 1
false easting        = 500000 m
false northing       = 0 m
unit                 = metre
zone prefix          = false
```

系统为自定义投影分别评分 CAD X=东、Y=北和 CAD X=北、Y=东两种轴映射。不得为自定义投影伪造 EPSG 编号，也不得回退到最接近的标准中央经线。

## 候选与确认数据契约

候选及确认配置增加 `crs_source`：

- `epsg`：`epsg` 为整数，投影从 EPSG 数据库重建。
- `custom`：`epsg` 为 `null`，投影从受控字段重建。

自定义配置携带以下可审计字段：

```json
{
  "crs_source": "custom",
  "epsg": null,
  "central_meridian_deg": 118.83333333333333,
  "latitude_of_origin_deg": 0.0,
  "scale_factor": 1.0,
  "false_easting_m": 500000.0,
  "false_northing_m": 0.0,
  "ellipsoid": "GRS80"
}
```

服务端只接受上述固定值组合；确认时仍要求候选任务 ID、输入指纹和候选内容与当前任务产物一致。已存在的 EPSG 配置缺少 `crs_source` 时按 `epsg` 读取，保持向后兼容。

工作流投影函数根据 `crs_source` 重建 CRS。候选评分、确认后的 SRT 轨迹构建和后续恢复必须使用同一重建函数，保证预览与工作台坐标一致。

## 前端行为

字段标题改为“CGCS2000 中央经线”，提示示例为“例如 120 或 118°50′；留空自动推荐”。候选卡片显示：

- 标准候选：EPSG 编号和中央经线。
- 自定义候选：`CGCS2000 自定义高斯—克吕格（中央经线 118°50′）`，不显示虚假 EPSG。

候选任务运行期间继续禁用输入；恢复任务时，从规范化十进制度格式化为便于阅读的度或度分形式。确认、更换 CAD/SRT、修改中央经线导致候选失效的规则保持不变。

## 错误处理

- 分数大于等于 60：提示“分必须小于 60”。
- 非法符号、多个小数点或无法解析：提示可接受的输入示例。
- 中央经线超出范围：提示必须位于 `-180°` 到 `180°`。
- 自定义 CRS 构造失败：候选任务失败并保留明确的投影参数，不自动换用标准 EPSG。
- 自定义候选确认数据被修改：按现有候选完整性校验拒绝确认。

## 测试与验收

测试必须先失败再实现，覆盖：

1. 度分、ASCII 分号、空格分隔和十进制度的等价解析。
2. 非法分钟、范围和文本的拒绝。
3. `120` 仍生成 EPSG:4549 候选。
4. `118°50′` 生成 `epsg=null` 的自定义候选，并使用精确中央经线。
5. 同一 WGS84 点通过候选评分和确认后工作流投影得到一致坐标。
6. 自定义候选可持久化、恢复、确认，并参与输入指纹与失效判断。
7. 前端字段、帮助文案、请求规范化和候选展示。

真实数据验收使用当前项目的 CAD、SRT 和 `118°50′`：重新生成候选后检查轨迹落入 CAD 范围、候选预览可见、结果可显式确认。完成自动化测试和真实项目冒烟后，重启 `127.0.0.1:8310` 服务供用户验证。

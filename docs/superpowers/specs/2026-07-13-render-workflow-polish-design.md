# 渲染工作流收尾设计

## 目标

在不改变旧版双视图、底部相机编辑和渲染算法的前提下，收尾质量检测到渲染导出的用户流程。

## 交互

- 质量检测面板增加“完成质量检测”按钮。该操作只将 `selectedWorkflowStage` 切换为 `render`，不会启动任务或重新计算质量。
- 渲染导出面板继续提供“渲染视频”“预览视频”“下载结果”。
- 进入渲染面板时，前端通过 `HEAD` 检查 `08_render/sfm_align_overlay.mp4`：文件存在则启用预览与下载；不存在则保持禁用并提示可启动渲染。
- 渲染 job 完成后沿用现有 job-status 成功刷新机制，重新检查产物并保持在渲染导出阶段。

## 控件收敛

底部旧审核控件 `审核：未加载`、`确认预测`、`保存微调关键帧`、`拒绝` 默认隐藏，保留 DOM 和旧代码，避免影响旧轨迹导入或相机编辑逻辑。

## 边界

- 不修改 `render_overlay`、对齐、质量算法或相机轨迹。
- 不新增前端构建链或后台队列。
- 继续由已有 `JobRunner` 以 `cadscene.cli.render_overlay` 执行渲染。

## 验证

- 静态测试验证质量面板的完成按钮、审核控件默认隐藏、渲染产物状态检查与 render job 调用。
- 复用现有合成视频渲染和 serve_viewer workflow API 测试；不运行真实长视频渲染。

# 后台并发、渲染发布、旋转进度与场景定位设计

## 目标

- 重型算法运行时，上传、新建项目、其他项目 CAD 替换等操作仍可执行。
- 修复渲染产物有效但在 99% 发布失败的问题。
- 将纯旋转片段准备和轨迹反算展示为一条单调、真实的进度。
- 允许已完成路线拟合的片段把边界相机位姿传给同场景相邻片段。

## 设计

### 资源隔离并发

保留现有本地持久化队列及资源容量约束，运行时按总资源容量启动多个 worker。队列继续保证同一资源类的并发上限，因此重型计算默认仍为一个；轻型计算、媒体 IO 和控制任务可以与重型任务并行。

同一项目修改了运行中任务的输入时，任务进程不被强杀，但完成结果必须由既有输入指纹校验标记为 `stale_input`，不得发布旧输入结果。

### 渲染发布身份

适配器输出 revision 只描述产物内容，不能直接作为项目不可变发布目录。服务端验证视频、frame map 和媒体契约后，使用任务 ID、输入指纹、适配器身份和验证证明派生项目发布 revision。相同任务重试可复用；不同任务或输入即使产生相同字节，也不会发生目录身份碰撞。已有发布目录继续按原清单读取。

### 单一纯旋转进度

管理快照把片段导出依赖映射到整体 0–15%，把纯旋转主任务映射到 15–99%，成功后为 100%。主任务运行时流式读取外部 OpenGV 后端已有的 `evaluated through decoded frame N` 输出，并以权威片段 frame map 的帧数为分母上报真实处理进度；转换、发布和校验占剩余区间。进度在任务切换时必须单调，不能回到 5%。

### 相邻片段定位

按钮位于已保存路线拟合成果的源片段：

- 向上定位：源路线起点 → 同场景上一片段末帧；
- 向下定位：源路线终点 → 同场景下一片段首帧。

服务端只读取通过校验的不可变 workbench 输出，并创建带来源证明的不可变定位种子。种子记录源/目标片段、源 workbench revision、方向、目标帧、相机位姿和操作 ID。目标片段存在活动会话或已有保存成果时拒绝覆盖。定位成功后打开目标片段工作台并跳到对应边界帧；继承位姿作为一个已确认的场景边界锚点，但不把目标片段标记为已经完成路线拟合。

## 验证

- 重型任务阻塞期间，轻型和媒体任务可由其他 worker 执行。
- 同项目输入变化后旧任务结果为 `stale_input`。
- 不同输入产生相同渲染字节时可分别发布，重试仍幂等。
- 导出到纯旋转反算的可见进度单调且由实际处理帧驱动。
- 上下定位严格限制在同场景相邻片段，端点、目标帧和来源 revision 正确。
- 运行聚焦、前端契约、全量测试及真实项目 smoke。

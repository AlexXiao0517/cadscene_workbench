# 无 XML 联合约束空三对齐设计

## 目标

针对“视频 + 缺失姿态 SRT + CGCS2000 CAD”的场景，在不读取 Bentley XML 的条件下，生成位置与姿态处于同一世界坐标变换中的相机轨迹，降低当前实验视频中 CAD 随时间产生的视差式漂移，并输出一版可直接对比的 1080p、30 fps 渲染视频。

Bentley XML 只能在求解完成、参数冻结之后用于离线误差报告。求解入口、缓存身份、轨迹文件和渲染入口均不得接受 XML 路径。

## 已确认问题

当前无 XML 原型对 COLMAP 相机中心和相机旋转分别使用了两个全局旋转：中心使用 SRT 位置拟合的 Sim3，旋转使用 DJI 元数据拟合的姿态标架。两个旋转相差约 3.25°，破坏了 COLMAP 位姿原本的刚性关系。诊断显示画面中心附近的预期偏移主要来自位置低频误差和姿态标架误差，FOV 差异不是主要因素。

DJI 航向、云台俯仰与机身姿态需要按 Bentley `XRightYDown` 完整矩阵约定组合。对照答案表明，该约定可将现有姿态标架误差从约 4.84°降至约 1.89°，但单独替换矩阵仍不能解决位置—姿态分裂定标。

## 方案选择

采用“单一世界 Sim3 + Bentley 姿态先验 + 固定安装角 + 低频位置修正”的联合鲁棒优化。

不采用以下方案：

- 直接使用 Bentley XML 旋转矩阵：效果稳定，但违反无 XML 约束。
- 继续对位置和姿态分别拟合全局旋转：局部位置可正确，但会产生随航线变化的投影漂移。
- 只使用 SRT 拟合出的单一 Sim3：保留刚性，但近直线航迹不能稳定确定绕航线方向的旋转，整体姿态可能倾斜约数度。
- 首版直接增加 CAD—图像边缘自动配准：搜索空间和场景依赖明显，先保留为联合约束仍不足时的第二阶段方案。

## 输入边界

求解允许输入：

- 1080p、每 0.5 秒抽帧得到的 COLMAP 稀疏模型；
- 原始视频及其 `djmd` 元数据；
- 原始 SRT 的经纬度、绝对高度与时间轴；
- 用户整数水平 FOV；
- 已确认的 CGCS2000 中央经线与 CAD 原点。

渲染额外允许输入：

- 原始 CAD 图层、颜色与线几何；
- `zhix.tpkg` 和 `station.tpkg` 地形高程。

Bentley XML 不属于求解或渲染输入，只属于独立验证命令的可选答案文件。

## 坐标与姿态约定

COLMAP 输出相机中心 `C_i` 和相机到世界旋转 `R_i`。所有相机共同使用一个待估计世界相似变换：

```text
P_i = s · G · C_i + t + d(t_i)
Q_i = G · R_i
```

其中 `s/G/t` 是唯一的全局 Sim3；`d(t_i)` 是受强平滑约束的低频 XYZ 修正。旋转不得再使用另一套全局标架。

DJI 元数据先生成 Bentley 相机姿态先验：

```text
T_i = BentleyXRightYDown(
    yaw   = aircraft_yaw,
    pitch = gimbal_pitch,
    roll  = bounded_aircraft_attitude_term
)
```

再估计一个全片固定、接近单位阵的安装角 `B`，表示 DJI 元数据坐标与实际光学相机坐标之间的固定偏差。`B` 必须有角度范围和零均值正则，不能自由吸收整个世界旋转。

## 联合目标函数

优化变量为 `s, G, t, B` 和稀疏低频位置修正节点 `d_k`。目标函数包含：

```text
E = Σ ρp(||P_i - SRT_i|| / σp)
  + Σ ρr(||Log((T_i · B)^T · Q_i)|| / σr)
  + λd Σ ||Δ²d_k||²
  + λb ||Log(B)||²
  + λe (||d_first||² + ||d_last||²)
```

- 位置和姿态使用鲁棒损失，避免个别 GPS 或 DJI 姿态异常值支配结果。
- 安装角首版限制在每轴 ±6°；超界视为模型不可辨识并报告失败，不静默扩大范围。
- 低频修正节点默认每 20 秒一个，只修正 XYZ，不为每帧增加独立自由度。
- SRT 高度基准原样保留；地形垂直基准差仍属于渲染/关键帧微调阶段，不在本次优化中伪造固定高度。
- COLMAP 相对位姿和稀疏点云保持不变，不重新运行特征提取或稀疏重建。

## 数据流与输出

1. 读取现有 COLMAP 模型、SRT 和视频 `djmd`。
2. 使用 SRT Sim3 和 Bentley 姿态矩阵产生联合优化初值。
3. 运行鲁棒最小二乘并记录初始/最终各损失项、安装角和收敛原因。
4. 将 0.5 秒相机姿态用四元数 SLERP 插值到源视频帧；位置使用平滑样条插值。
5. 输出独立的相机轨迹、相机内参和联合优化报告。
6. 当前算法实验使用原始 CAD 颜色与 TPKG 高程生成三个探针帧，人工确认后再输出有效运动区间 1920×1080、30 fps 完整视频。
7. 正式平台任务不设置探针确认门禁；联合优化完成后直接进入既有工作台、关键帧微调和独立渲染流程。
8. 最后单独运行 XML 对照命令；该命令只读取已经冻结的结果，不回写任何参数。

## 失败与降级

- `djmd` 缺失或字段无法解码：停止联合优化，保留单一 SRT Sim3 结果并明确标记“需要姿态关键帧”，不恢复到位置/姿态分裂标架。
- 优化不收敛、安装角触及边界或最终姿态残差上升：拒绝覆盖基线结果，保存诊断报告。
- SRT 位置异常点：由鲁棒损失降权，并在报告中列出帧号。
- 当前算法实验的探针出现视锥翻转、CAD 整体旋转错误或投影非有限值：不启动实验完整视频渲染；正式平台依赖任务状态与既有工作台诊断，不增加探针确认状态。

## 验收标准

无 XML 自动验收：

- 求解与渲染报告均声明 `xml_used=false`，命令行接口不存在 XML 参数；
- COLMAP 中心和旋转使用完全相同的全局 `G`；
- 输出覆盖原视频全部 12,017 帧，旋转四元数有限且归一化；
- SRT 中心残差不高于当前基线的 1.5 倍；
- DJI 姿态鲁棒残差较初值下降；
- 当前算法实验的三个探针帧没有姿态翻转或 CAD 主体离开施工带。

冻结后的 XML 对照验收：

- XML 只出现在验证报告的 `reference_only` 字段；
- 相对于当前无 XML 视频，预测画面漂移 P95 明显下降；
- 完整视频由用户依据 CAD 是否稳定贴合道路和结构物进行最终视觉确认。

## 测试策略

- 矩阵单元测试：Bentley `XRightYDown` 组合、旋转正交性、欧拉角边界与固定安装角。
- 优化合成测试：已知 Sim3、安装角和低频偏移能够被恢复；异常位置/姿态样本不会拉偏结果。
- 契约测试：求解器和渲染器不接受 XML，中心与旋转共享同一个 `G`。
- 轨迹测试：SLERP、位置样条、首尾钳制、12,017 帧覆盖。
- 回归测试：现有 CAD/TPKG 三维渲染和完整姿态 SRT 路径不受影响。
- 实验验收：先探针、后整片；正式平台不包含探针确认门禁；XML 对照必须在结果冻结后独立执行。

# 工作台退出与恢复状态设计

## 目标

用户关闭浏览器页面或整合包服务后，再次进入同一片段时，应恢复到上次已持久化的工作状态。恢复内容包括已保存关键帧、当前有效路线、质量检测和渲染进度、工作流步骤，以及上次停留的权威源视频 PTS。尚未保存的相机拖动不写入项目，但关闭或刷新网页时必须提示用户这些修改不会保留。

## 权威数据与恢复状态

现有项目产物继续作为业务结果的权威来源：

- `camera_track_manual.json` 保存用户确认的人工关键帧；
- `camera_track_pred.json` 保存最近一次路线拟合结果；
- ProjectService 的项目、片段、任务和 workbench output revision 保存轨迹、质量、渲染及后台任务状态；
- annotation、render 和其他既有 manifest 不改变职责。

每个片段新增轻量、原子写入的工作台恢复状态。恢复状态只记录导航信息，不复制业务产物：

- schema version；
- project id 和 clip id；
- 当前工作流步骤；
- source decoded-frame integer PTS；
- exact source time base；
- 写入时所引用的 trajectory、workbench output、quality 和 render revision；
- 最近更新时间。

恢复状态不保存尚未确认的相机姿态，也不把浏览器临时状态写入 clips/jobs manifest。

## 关键帧与路线恢复

重新打开 SfM 工作台时：

1. 读取当前有效的拟合轨迹作为连续播放基线；
2. 独立读取最新的人工关键帧文件；
3. 按源帧合并二者，同帧由人工关键帧覆盖；
4. 人工关键帧仍保持人工来源标记，并继续参与下一次路线拟合；
5. 如果拟合轨迹不存在，则只加载人工关键帧；
6. 如果人工关键帧不存在，则保持现有拟合轨迹行为。

这样，路线拟合后新增但尚未重新拟合的人工关键帧在重开后仍可见，同时不会丢失完整的拟合路线。

## 工作流步骤恢复

恢复状态中的步骤是用户上次停留位置，但服务端必须用当前持久化产物校验它：

- 对应产物仍有效时恢复到记录步骤；
- 记录步骤所需产物缺失或失效时，退回最近一个有效步骤；
- 后台任务状态始终从 ProjectService/任务队列读取，不从恢复状态伪造；
- 服务重启后，进行中、排队、取消、成功和失败状态沿用现有耐久任务恢复规则；
- 已完成质量检测或渲染的片段不会因新建工作台会话而回退到更早阶段。

工作台和项目管理界面继续使用同一项目快照作为任务进度来源。

## 视频位置恢复

视频位置以 source decoded-frame integer PTS 和 exact time base 保存。浏览器在 pause、seek、阶段切换和保存操作后防抖提交；正式值不使用 `currentTime × fps` 或固定 FPS 帧号推导。

重开后，前端在权威 decoded-frame 时间轴中定位该 PTS；若该 PTS 已不属于当前片段范围，则夹取到当前片段最近的合法 PTS。

## 未保存修改提醒

用户拖动或修改虚拟相机后，前端设置内存态 dirty 标记。成功保存关键帧、删除关键帧或明确放弃修改后清除标记。

当 dirty 标记存在时，刷新或关闭页面触发标准 `beforeunload` 提醒。浏览器可能使用自己的统一提示文本，这是浏览器安全限制。关闭整合包服务本身不把临时相机姿态自动保存为关键帧。

## 存储与整合包行为

恢复状态与现有项目数据一起写入整合包的 `workspace`。关闭启动脚本不会删除该目录。重新解压到另一个目录会创建另一个独立 `workspace`，不会自动引用原目录的项目。

所有恢复状态使用 expected revision、operation id 和原子 JSON 替换，避免并发页面或服务中断产生半写文件。旧项目没有恢复状态时继续使用现有产物推导步骤，并从片段起始 PTS 打开，保持向后兼容。

## 错误处理

- 恢复状态损坏或 schema 不支持：忽略该状态，从现有产物推导，不阻止进入工作台；
- revision 已失效：忽略不匹配字段并退回有效步骤；
- PTS 不在当前片段：夹取到最近合法 PTS；
- 恢复状态写入冲突：前端刷新最新 revision 后仅重试导航状态，不覆盖业务产物；
- 人工关键帧读取失败：明确提示关键帧恢复失败，不用旧拟合轨迹伪装成完整恢复。

## 测试范围

按 TDD 覆盖：

- 路线拟合后新增人工关键帧，重开仍显示且人工帧覆盖同帧预测；
- 只有人工轨迹或只有拟合轨迹时的兼容行为；
- 已完成关键帧、质量检测和渲染步骤重开不回退；
- 进行中后台任务重启后继续显示同一任务状态和进度；
- source PTS/time base 的写入、夹取和恢复；
- 未保存相机拖动触发关闭提醒，成功保存后不提示；
- 恢复状态损坏、过期 revision 和旧项目缺少恢复状态时的降级；
- 整合包关闭/启动 smoke，确认同一 `workspace` 的项目和恢复状态保持不变。

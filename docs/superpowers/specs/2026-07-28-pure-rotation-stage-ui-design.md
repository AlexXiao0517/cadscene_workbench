# Pure-Rotation 阶段化前端设计

日期：2026-07-28

## 目标与边界

将实验性的 Pure-Rotation 前端整理成用户可理解的线性闭环：

`上传数据 → 旋转轨迹恢复 → 关键帧标定 → 渲染导出`

Pure-Rotation 仅在无 SRT 且用户显式声明“无人机悬停，仅转动视角”时运行。无 SRT 默认仍为 `sfm_only`；有 SRT 时继续使用原 SRT 路由。本设计不实现自动悬停检测、平移估计、标准 SfM 修改或质量检测阶段。

## 交互原则

1. 阶段决定当前可用功能，不向普通用户暴露 Raw/Base/Corrected 等内部轨迹层。
2. 第三人称三维视图顶栏不再承载 Pure-Rotation 调试按钮。
3. 全局放置和当前帧姿态调整均实时作用于预览；保存不是播放的前置条件。
4. 相机中心在整段轨迹中严格固定。
5. 旋转矩阵和单位四元数是权威表示；Euler 仅用于显示和人工输入。
6. 关键帧变化后自动更新拟合预览，最终确认时重新生成并校验完整轨迹。

## 阶段 1：数据上传

### 按钮

- 选择视频
- 选择 CAD
- 选择 SRT（可选）
- 创建任务并继续

### 功能

- 无 SRT 时显示“无人机悬停，仅转动视角”选择，默认不选。
- 显式选择悬停后路由到 `pure_rotation`；未选择时路由到 `sfm_only`。
- 有 SRT 时隐藏或禁用悬停选择，不允许其覆盖现有 SRT 路由。
- 提交前显示视频、CAD、SRT、运动模式和工作流摘要。

## 阶段 2：旋转轨迹恢复

该阶段替换 Pure-Rotation 流程中的“SfM 重建”。

### 按钮

- 运行旋转轨迹恢复
- 重新运行
- 进入关键帧标定

### 功能

- 调用既有 External OpenGV 后端，不在前端或 API 重写旋转数学。
- 显示运行中、成功和 typed failure 状态。
- 成功后加载 PTS 姿态、segment 和质量摘要。
- 校验矩阵、固定中心、PTS 单调性和轨迹连续性。
- 在第三人称视图中预览恢复的视锥旋转，不显示 SfM 移动路径。
- 只有轨迹恢复并校验成功后，才允许进入关键帧标定。

## 阶段 3：关键帧标定

### 全局放置

#### 控件与按钮

- X、Y、Z
- Yaw、Pitch、Roll
- FOV
- 保存当前全局放置
- 恢复上次保存

#### 功能

- 参数和 Gizmo 调整立即更新草稿预览。
- 未保存草稿也能直接播放；播放使用当前草稿作为全局 anchor。
- X/Y/Z 是整个 segment 唯一的固定中心。
- FOV 仅修改显示投影，不重跑 OpenGV。
- 保存操作是持久化检查点，不是预览或播放的前置条件。

### 当前帧姿态微调

#### 控件与按钮

- 绕竖直轴旋转滑块，范围 `-180°～+180°`
- 滑块角度数值输入
- 水平旋转归零
- 普通三轴旋转 Gizmo
- 添加/更新当前关键帧
- 删除当前关键帧
- 上一个关键帧
- 下一个关键帧
- 撤销当前未保存调整

#### 水平旋转语义

- 旋转轴始终是 CAD 世界竖直轴。
- 旋转中心始终是固定相机中心。
- 滑块只改变姿态，不改变 X/Y/Z 或 FOV。
- 零点是进入当前帧时的已拟合姿态；拖动值是相对角度，不随输入事件重复累积。
- 使用世界竖直轴旋转矩阵左乘当前姿态，不通过 Euler 分量拼接实现。
- 普通旋转 Gizmo 保留，用于俯仰、侧倾和最终三轴微调。

### 路径拟合

- 每个关键帧保存 `DeltaR = R_manual @ R_base.T`。
- 残差转换为单位四元数并执行半球检查。
- 同一 segment 内相邻关键帧使用 SLERP。
- 第一个关键帧前保持第一个残差，最后一个关键帧后保持最后一个残差。
- 不线性插值 Euler，不跨 segment 插值，不拟合相机位置。
- 新增、修改或删除关键帧后自动更新拟合预览。

### 阶段完成按钮

- 完成标定并生成拟合轨迹

该操作校验全局放置与关键帧，重新生成完整轨迹，原子保存，并直接进入渲染导出。

## 阶段 4：渲染导出

### 按钮

- 预览拟合结果
- 返回关键帧标定
- 开始渲染
- 导出结果

### 功能

- 按 PTS 播放最终拟合轨迹。
- 相机中心固定，旋转使用矩阵或四元数插值。
- CAD overlay 使用最终拟合姿态。
- 显示渲染进度和失败原因。
- 导出渲染视频和必要的实验元数据。
- Pure-Rotation 不再经过质量检测阶段。

## 删除与迁移

删除第三人称视图顶栏中的以下调试控件：

- 隐藏/显示标注
- 导出相机轨迹
- 预览层级
- 固定相机放置预览
- 全局放置模式
- 保存固定相机放置
- 姿态关键帧模式
- 添加/更新姿态关键帧
- 删除当前姿态关键帧
- 聚焦相机与 CAD

仍有产品价值的“保存全局放置”和关键帧操作迁移到阶段 3 的底部参数区。Pure-Rotation 阶段导航中删除“质量检测”，并清除“拟合后进入质量检测”等旧文案。

## 状态与失败处理

- 后端失败时停留在阶段 2，显示 typed error，不静默切换 SfM。
- 未生成有效轨迹时不能进入阶段 3。
- 未校准 segment 不能生成 CAD 世界拟合轨迹。
- 保存或拟合失败不得覆盖上一份有效产物。
- segment break 后不继承上一 segment 的放置或关键帧残差。

## 验收要点

- Pure-Rotation 只有用户显式选择时运行。
- 顶栏调试按钮全部移除，功能按阶段归位。
- 草稿放置无需保存即可播放，并在播放中保持固定中心。
- 水平旋转滑块绕世界竖直轴工作，倾斜相机时无需联动调整两个局部轴。
- Gizmo 仍可用于三轴微调。
- 关键帧残差经 SLERP 形成连续拟合轨迹。
- Pure-Rotation 从关键帧标定直接进入渲染导出，不出现质量检测。
- 原有 SfM 与 SRT 工作流行为不变。

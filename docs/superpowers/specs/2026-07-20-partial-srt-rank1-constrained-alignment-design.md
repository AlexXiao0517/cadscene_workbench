# Stage 6B-1b：Rank-1 Partial-SRT 约束对齐设计草案

## 1. 问题背景

已完成的脱敏真实数据复核表明：视频与 SRT 的时间同步正确，PTS 和原视频帧号映射一致，GPS/高度覆盖充分，空间去重后仍有足够样本，且水平基线充足。全视频轨迹仍近似直线：空间秩为 1，线性比约为 0.003，标准三维 Sim3 因 `rank-below-two` 与 `near-linear` 正确拒绝。

这不是 SfM 未生成轨迹、时间偏移、GPS 重复或短基线问题，而是位置约束本身缺少第二个独立方向。

## 2. Rank-1 可观测与不可观测自由度

两条时间配对的位置轨迹可以确定：

- SfM 与 ENU 的主运动方向；
- 沿程尺度；
- 轨迹中心的平移；
- 沿程低频位置约束。

仅凭直线位置轨迹无法唯一确定：

- 绕主运动方向的旋转；
- SfM 世界 Up 与 ENU Up 的唯一关系；
- 完整三维相机姿态变换；
- 稀疏点云在 ENU 中唯一的绕轴姿态。

## 3. 为什么不能直接降低阈值

以下做法均不可接受：删除 `rank-below-two` 检查、强制普通三维 Umeyama、将 Rank-1 当成普通二维平面轨迹、按 GPS 航向猜测相机 yaw、假定云台方向等于飞行方向，或输出带虚假高置信度的完整 Sim3。它们都会把未观测的绕轴自由度伪装为已确定量。

## 4. 最小约束方案

第一方向由位置轨迹提供：

1. 对 SfM 相机中心和 SRT ENU 位置分别做 PCA，得到 `d_sfm` 与 `d_enu`；
2. 以时间前进方向消除 PCA 向量的正负号歧义；
3. 施加 `R · d_sfm = d_enu`；
4. 在时间配对样本上，以鲁棒沿程距离斜率或中位数距离比估计尺度，而非使用单一首尾点；
5. 固定旋转和尺度后，以稳健质心估计平移，并分别输出位置残差与沿程残差。

该步骤只确定与主方向有关的部分变换；完整旋转仍需第二个非共线方向。

## 5. 第二方向先验

产品优先方案是使用一个已人工标定的相机/CAD 姿态关键帧，推导可靠的 Up、地面法向或相机方向约束；该方向与主运动方向共同构造完整正交基，从而消除绕轨迹方向的剩余旋转自由度。

备选先验包括完整云台姿态、IMU 重力方向、可信地面平面法向、已知 CAD 平面法向和测量控制点。它们分别受制于姿态时间对齐、传感器标定、平面可信度、坐标轴约定和测量误差；必须记录来源与残差，不能默认可信。

## 6. 无第二方向先验时的行为

没有可靠第二方向先验时，只允许输出 position-only diagnostic，以及沿程尺度和方向对齐统计；不得输出完整 `camera_trajectory_fused.json`，不得变换相机旋转或 SfM 点云，不得标记融合成功。用户应继续使用 `sfm_only`，或补充一个人工姿态关键帧。

## 7. 与现有标准流程的关系

- `rank >= 2`：继续使用现有标准三维 Sim3；
- `rank = 1` 且有第二方向先验：进入 Rank-1 constrained alignment；
- `rank = 1` 且无第二方向先验：只输出诊断；
- 近静止、基线过短或同步失败：保持拒绝。

本草案不修改现有标准 Sim3 或质量门。

## 8. 变换链

后续完整链路为：

`SfM camera/point → Rank-1 constrained SfM-to-ENU → ENU-to-CAD alignment → CAD world`

相机中心、相机旋转和 sparse point cloud 必须使用一致变换链：

`SfM-to-CAD = ENU-to-CAD ∘ SfM-to-ENU`

不能只变换融合相机轨迹而保留原始 SfM PLY 坐标。

## 9. 质量与置信度

未来应分别输出 `direction_alignment_error`、`along_track_scale_consistency`、`cross_track_residual`、`second_prior_angular_residual`、`position_confidence`、`orientation_confidence` 和 `prior_source`。

置信度仅表示内部一致性，不代表绝对定位误差；人工先验质量必须独立记录。

## 10. 下一阶段边界

本草案只定义方案，不实现。实施前仍需明确：人工关键帧可提供的具体姿态字段、CAD/ENU 轴方向约定、第二方向先验如何从现有标定结果提取、点云组合变换、合成 Rank-1 测试数据，以及无先验时的失败协议。

姿态先验的版本化 schema、兼容读取和资格门见 [Stage 6B-1b-a 文档](2026-07-22-orientation-prior-schema.md)。

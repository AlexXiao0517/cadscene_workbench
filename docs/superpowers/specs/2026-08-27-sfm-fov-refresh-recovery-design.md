# SfM 视场角刷新恢复设计

## 问题

SfM 已从相机内参计算出视场角，但前端通过 `sessionStorage` 跨页面刷新记录“已应用”。刷新后 Viewer 重新以 70° 默认值创建相机，而 Workflow 因旧标记跳过 SfM 初始化，导致界面显示错误的默认值。

## 设计

- SfM 初值只在当前页面实例内去重，不再跨刷新跳过。
- Viewer 明确报告是否已加载保存的相机轨迹。
- 如果存在保存的人工轨迹或路线拟合轨迹，保存结果优先，SfM 初值不得覆盖。
- 如果不存在保存轨迹，每次重新进入或刷新页面都从 SfM 内参恢复视场角。
- 不修改 SfM、路线拟合、相机轨迹文件或项目 manifest。

## 验证

- 刷新页面时不再依赖 `cadsceneSfmCameraInit` 的 `sessionStorage` 标记。
- 同一页面内的重复触发只发起一次初始化。
- 已加载保存轨迹时跳过 SfM 初值。
- 现有 Viewer 与 Pure Rotation 契约测试保持通过。

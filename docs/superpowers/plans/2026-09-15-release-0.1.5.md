# Windows offline release 0.1.5 Implementation Plan

> **For agentic workers:** Execute this release plan inline with verification gates; use code review before publishing.

**Goal:** Synchronize the accepted SRT/rendering implementation into the local main system and deliver the same portable Windows ZIP format as0.1.4.

**Architecture:** Preserve the existing SRT worktree as integration workspace. Commit only reviewed application/tests/docs changes (never tmp/data), integrate main's retention/migration/draft fixes, validate, and fast-forward main only when ready. Build an isolated runtime containing the new wheel, pinned Pure Rotation backend, launchers and resources.

**Tech Stack:** Python, pytest, setuptools wheel, conda-pack, PowerShell launchers, ZIP64.

## Global constraints

- Preserve all existing project data, source videos/SRT/CAD, old packages and experiment files.
- Release0.1.5 must contain regional renderer, full-pose smoothing/assets, incomplete-SRT reconstruction and main's existing fixes.
- Do not include developer workspaces, recordings, tests or historical logs in delivery.
- Keep relative-height option and terrain option; don't silently change height choice.
- Build archive into a new0.1.5 directory; no overwriting an existing release.
- No push, no worktree removal. Current workspace storage remains work/srt-full-pose-ui-test.

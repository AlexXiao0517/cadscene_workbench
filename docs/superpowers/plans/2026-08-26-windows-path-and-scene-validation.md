# Windows 路径与视频场景复核实施计划

## 目标

- 离线包在上传前发现 Windows 路径预算不足，并用清晰提示阻止必然失败的任务。
- 连续航拍视频的粗采样变化只作为候选，经过局部密集帧复核后才成为场景边界。
- 保持整数 source PTS、严格小于 60 秒的片段划分和既有工作流契约。

## TDD 步骤

1. 先增加离线包短目录名、启动路径预算检查和 `psutil` 运行时校验的失败测试，再实现启动器修复。
2. 先增加候选边界密集复核、开场黑场合并和 PTS 映射的失败测试，再实现分析器修复。
3. 使用 `yjq` 的 6 分 38 秒真实视频重新分析，检查场景数、片段时长及完整帧分区。
4. 运行聚焦测试、全量测试、依赖检查和 `git diff --check`，分模块提交，不合并 `main`。
